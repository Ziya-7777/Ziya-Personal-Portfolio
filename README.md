# Ziya Malkani — Portfolio

A responsive React + Vite portfolio with a sage, blush, and burgundy visual identity, custom CSS artwork, project filters, scroll reveals, floating elements, mobile navigation, your profile photo, a light/dark toggle, and a downloadable starter résumé PDF.

## Run locally

Requires Node.js (use a current version supported by Vite).

```bash
npm install
npm run dev
```

Open the local URL shown in your terminal.

## Production build

```bash
npm run build
npm run preview
```

## Before publishing — personalize these details

1. Replace `ziya.malkani@example.com` in `src/App.jsx` with your real professional email.
2. Update the LinkedIn link to your actual profile URL.
3. Check each GitHub repository URL and make sure the repository names are public and correct.
4. Review `public/ziya-malkani-resume.pdf`; it is a starter résumé based on the information available and should be checked for accuracy before applying. Replace it with your final résumé PDF when ready.
5. Confirm that the descriptions and technologies match your actual contributions before using this as a job application portfolio.

## Deploy to Vercel

Push this folder to a GitHub repository, import the repository into Vercel, and keep the default Vite settings:
- Build command: `npm run build`
- Output directory: `dist`

This is a frontend portfolio. It does not need a database or backend to run.
